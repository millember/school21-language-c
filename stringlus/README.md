# s21_string+

Реализация библиотеки string.h с дополнениями (sprintf, sscanf и специальные функции обработки строк).

## Быстрый старт

### Компиляция библиотеки:
```bash
make s21_string.a
```

### Запуск тестов:
```bash
make test
```

### Генерация отчета покрытия кода:
```bash
make gcov_report
```

### Проверка стиля кода:
```bash
make clang
```

### Проверка статическим анализатором:
```bash
make cppcheck
```

### Очистка:
```bash
make clean
```

### Пересборка:
```bash
make rebuild
```

## Реализованные функции

### 1. Основные функции string.h

- **s21_memchr** - поиск первого вхождения символа в памяти
- **s21_memcmp** - сравнение блоков памяти
- **s21_memcpy** - копирование памяти
- **s21_memset** - заполнение памяти значением
- **s21_strncat** - конкатенация строк с ограничением длины
- **s21_strchr** - поиск первого вхождения символа в строке
- **s21_strncmp** - сравнение строк с ограничением длины
- **s21_strncpy** - копирование строк с ограничением длины
- **s21_strcspn** - длина начального сегмента без указанных символов
- **s21_strerror** - получение строки ошибки (поддержка macOS/Linux)
- **s21_strlen** - вычисление длины строки
- **s21_strpbrk** - поиск любого символа из набора
- **s21_strrchr** - поиск последнего вхождения символа
- **s21_strstr** - поиск подстроки
- **s21_strtok** - разбиение строки на токены

### 2. Функция sprintf (частичная реализация)

**Поддерживаемые спецификаторы:**
- `%c` - символ
- `%d` - знаковое десятичное целое
- `%f` - число с плавающей точкой
- `%s` - строка
- `%u` - беззнаковое десятичное целое
- `%%` - символ процента

**Поддерживаемые флаги:**
- `-` - выравнивание по левому краю
- `+` - обязательный вывод знака
- `(пробел)` - пробел перед положительными числами

**Поддерживаемые описатели:**
- `ширина` - минимальное количество символов
- `.точность` - точность для чисел/максимум символов для строк
- `h` - short int
- `l` - long int

### 3. Дополнительные модификаторы sprintf (бонус)

**Дополнительные спецификаторы:**
- `%g`, `%G` - кратчайшее представление
- `%e`, `%E` - научная нотация
- `%x`, `%X` - шестнадцатеричное целое
- `%o` - восьмеричное целое
- `%p` - указатель

**Дополнительные флаги:**
- `#` - альтернативная форма
- `0` - заполнение нулями

**Дополнительные описатели:**
- `*` - динамическая ширина/точность
- `L` - long double

### 4. Функция sscanf (бонус)

Полная реализация функции sscanf с поддержкой всех спецификаторов, флагов и описателей.

### 5. Специальные функции обработки строк (бонус)

- **s21_to_upper** - преобразование строки в верхний регистр
- **s21_to_lower** - преобразование строки в нижний регистр
- **s21_insert** - вставка строки в указанную позицию
- **s21_trim** - удаление указанных символов с начала и конца строки

## Примеры использования

```c
#include "s21_string.h"

int main() {
    // Использование стандартных функций
    char str1[20] = "Hello";
    char str2[] = " World!";
    s21_strncat(str1, str2, 7);
    printf("%s\n", str1);  // "Hello World!"
    
    // Использование sprintf
    char buffer[100];
    s21_sprintf(buffer, "Число: %d, Строка: %s", 42, "test");
    printf("%s\n", buffer);  // "Число: 42, Строка: test"
    
    // Использование sscanf
    int num;
    char text[20];
    s21_sscanf("123 abc", "%d %s", &num, text);
    printf("%d %s\n", num, text);  // "123 abc"
    
    // Использование специальных функций
    char *upper = s21_to_upper("hello");
    printf("%s\n", upper);  // "HELLO"
    free(upper);
    
    return 0;
}
```
