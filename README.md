### 🔧 Системные утилиты
**Реализации стандартных Unix-утилит с нуля**

#### 🐱 s21_cat
**Реализация утилиты `cat` для вывода содержимого файлов**
- **Описание:** Полная клон-утилита GNU cat с поддержкой всех основных флагов
- **Поддерживаемые флаги:**
  - `-b`, `--number-nonblank` - нумерация непустых строк
  - `-e`, `-E`, `--show-ends` - отображение концов строк
  - `-n`, `--number` - нумерация всех строк
  - `-s`, `--squeeze-blank` - сжатие пустых строк
  - `-t`, `-T`, `--show-tabs` - отображение табуляций
  - `-v` - отображение непечатаемых символов
- **Особенности:**
  - Полная совместимость с оригинальной утилитой
  - Поддержка длинных опций (GNU-стиль)
  - Корректная обработка непечатаемых символов
  - Автоматическое тестирование через bash-скрипты
- **Технологии:** C (стандарт C11), getopt_long для парсинга опций
- **Статус:** ✅ Завершён

#### 🔍 s21_grep
**Реализация утилиты `grep` для поиска текста по шаблонам**
- **Описание:** Поисковая утилита с поддержкой регулярных выражений
- **Поддерживаемые флаги:**
  - `-e` - указание шаблона поиска
  - `-i` - игнорирование регистра
  - `-v` - инвертированный поиск
  - `-c` - подсчёт количества совпадений
  - `-l` - вывод только имён файлов
  - `-n` - вывод с номерами строк
  - `-f` - загрузка шаблонов из файла
  - `-o` - вывод только совпадающих частей
- **Особенности:**
  - Поддержка регулярных выражений (POSIX Extended)
  - Оптимизированный алгоритм поиска
  - Работа с большими файлами (буферизация)
  - Автоматическое тестирование
- **Технологии:** C (стандарт C11), regex.h для регулярных выражений
- **Статус:** ✅ Завершён

### 📊 Math Function Plotter
**Построитель графиков математических функций в терминале.**
- **Описание:** Программа для визуализации математических функций с использованием ASCII-графики
- **Поддерживаемые функции:** sin(x), cos(x), tan(x), ctg(x), sqrt(x), ln(x), арифметические операции
- **Особенности:**
  - Преобразование выражений в обратную польскую нотацию (RPN)
  - Автоматическое масштабирование графика
  - Валидация математических выражений
  - Поле 80×25 символов
- **Технологии:** C (стандарт C11), математическая библиотека
- **Статус:** ✅ Завершён

### 🎮 Pong Game
**Классическая аркадная игра для терминала с ASCII-графикой.**
- **Описание:** Двухмерный симулятор настольного тенниса для двух игроков
- **Режимы:** 
  - Пошаговый (консольный, без зависимостей)
  - Интерактивный (реальное время с библиотекой ncurses)
- **Особенности:**
  - Поле 80×25 символов
  - Ракетки по 3 символа, мяч — 1 символ
  - Управление: A/Z (игрок 1), K/M (игрок 2)
  - Игра до 21 очка
- **Технологии:** C (стандарт C11), ncurses
- **Статус:** ✅ Завершён

### 🧠 s21_string+
**Полная реализация стандартной библиотеки string.h с дополнениями.**
- **Описание:** Создание собственной библиотеки обработки строк с поддержкой форматированного ввода/вывода
- **Основные возможности:**
  - **Функции string.h:** memchr, memcmp, memcpy, memset, strncat, strchr, strncmp, strncpy, strcspn, strerror, strlen, strpbrk, strrchr, strstr, strtok
  - **Форматированный вывод:** sprintf с поддержкой спецификаторов c, d, f, s, u, %
  - **Форматированный ввод:** sscanf с полной поддержкой форматов
  - **Специальные функции:** to_upper, to_lower, insert, trim
- **Особенности реализации:**
  - Полное покрытие тестами (более 80% каждой функции)
  - Кроссплатформенность (macOS/Linux)
  - Генерация HTML-отчетов покрытия (gcovr)
  - Автоматическая проверка стиля кода
  - Поддержка long options в Makefile
- **Технологии:** C (стандарт C11), Check для тестирования, gcov для покрытия
- **Статус:** ✅ Завершён

### 🧮 s21_matrix+
**Реализация библиотеки для работы с матрицами.**
- **Описание:** Создание собственной библиотеки линейной алгебры с полным набором операций над матрицами
- **Основные возможности:**
  - **Создание и управление:** создание, удаление, копирование матриц
  - **Базовые операции:** сложение, вычитание, умножение на скаляр, умножение матриц
  - **Линейная алгебра:** транспонирование, вычисление определителя, матрицы алгебраических дополнений, обратная матрица
  - **Сравнение:** проверка равенства матриц с заданной точностью
- **Особенности реализации:**
  - Рекурсивный алгоритм вычисления определителя через миноры
  - Метод алгебраических дополнений для обратной матрицы
  - Оптимизированные алгоритмы для матриц 1×1 и 2×2
  - Полное покрытие тестами всех операций
  - Проверка утечек памяти с помощью valgrind
  - HTML-отчеты покрытия кода (gcovr)
- **Технологии:** C (стандарт C11), Check для тестирования, valgrind для проверки памяти
- **Статус:** ✅ Завершён

### s21_decimal+
**Реализация библиотеки для работы с decimal-типом данных.**
- **Описание:** Создание собственной реализации типа данных decimal для точных вычислений с фиксированной точкой
- **Основные возможности:**
  - **Арифметические операции:** сложение, вычитание, умножение, деление
  - **Сравнение:** меньше, меньше или равно, больше, больше или равно, равно, не равно
  - **Преобразования:** из int/float в decimal и обратно
  - **Математические функции:** округление, усечение, взятие целой части, изменение знака
- **Особенности реализации:**
  - Поддержка чисел до 28 знаков после запятой
  - Работа с большими числами через s21_big_decimal (192-битная мантисса)
  - Банковское округление (round half to even)
  - Обработка переполнений и ошибок (INF, -INF, NAN)
  - Подробное тестирование всех граничных случаев
- **Технологии:** C (стандарт C11), Check для тестирования, gcov для покрытия, valgrind для проверки памяти
- **Статус:** ✅ Завершён
