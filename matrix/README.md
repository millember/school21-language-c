# s21_matrix+

Реализация библиотеки для работы с матрицами на языке C. Аналог библиотеки для работы с матрицами, включая все основные операции линейной алгебры.

## 📊 Основные возможности

### Создание и управление матрицами
- **Создание матрицы** произвольных размеров
- **Очистка матрицы** с освобождением памяти
- **Копирование матриц**

### Базовые операции
- **Сложение** матриц одинаковых размеров
- **Вычитание** матриц одинаковых размеров  
- **Умножение** на скаляр
- **Умножение** матриц (с учетом совместимости размеров)

### Продвинутые операции линейной алгебры
- **Транспонирование** матрицы
- **Вычисление определителя** (детерминанта)
- **Вычисление матрицы алгебраических дополнений**
- **Нахождение обратной матрицы**

### Вспомогательные функции
- **Сравнение матриц** с заданной точностью
- **Валидация** входных данных
- **Обработка ошибок** с кодами возврата

## 🔧 Реализованные функции

### 1. Создание и удаление
- **`s21_create_matrix`** - создание матрицы заданного размера
- **`s21_remove_matrix`** - освобождение памяти, занятой матрицей

### 2. Сравнение
- **`s21_eq_matrix`** - сравнение двух матриц с заданной точностью (1e-7)

### 3. Арифметические операции
- **`s21_sum_matrix`** - сложение двух матриц
- **`s21_sub_matrix`** - вычитание матриц
- **`s21_mult_number`** - умножение матрицы на число
- **`s21_mult_matrix`** - умножение двух матриц

### 4. Линейная алгебра
- **`s21_transpose`** - транспонирование матрицы
- **`s21_calc_complements`** - вычисление матрицы алгебраических дополнений
- **`s21_determinant`** - вычисление определителя матрицы
- **`s21_inverse_matrix`** - нахождение обратной матрицы

## 📊 Примеры использования

```c
#include "s21_matrix.h"

int main() {
    // Создание матриц 3x3
    matrix_t A, B, result;
    
    // Создаем матрицы
    s21_create_matrix(3, 3, &A);
    s21_create_matrix(3, 3, &B);
    
    // Заполняем значениями
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            A.matrix[i][j] = i * 3 + j + 1;
            B.matrix[i][j] = i * 3 + j + 1;
        }
    }
    
    // Сложение матриц
    s21_sum_matrix(&A, &B, &result);
    
    // Вычисление определителя
    double det;
    s21_determinant(&A, &det);
    printf("Определитель: %f\n", det);
    
    // Нахождение обратной матрицы
    matrix_t inverse;
    s21_inverse_matrix(&A, &inverse);
    
    // Очистка памяти
    s21_remove_matrix(&A);
    s21_remove_matrix(&B);
    s21_remove_matrix(&result);
    s21_remove_matrix(&inverse);
    
    return 0;
}
```

## 🧪 Тестирование

Проект включает полный набор модульных тестов, проверяющих:

### ✅ Функциональные тесты
- **Корректность операций** (сложение, вычитание, умножение)
- **Правильность вычислений** линейной алгебры
- **Обработка граничных случаев**

### 🛡️ Тесты на ошибки
- **Некорректные размеры** матриц
- **Невозможность операций** (несовместимые размеры)
- **Вырожденные матрицы** (определитель = 0)
- **Обработка NULL-указателей**

### 🔍 Тесты точности
- **Сравнение с ожидаемым результатом** с заданной точностью
- **Тестирование на сингулярных матрицах**
- **Проверка корректности обратной матрицы** (A × A⁻¹ = I)

### 📈 Покрытие кода
- **Более 80% покрытия** каждой функции
- **HTML-отчет** gcovr с детализацией покрытия
- **Отчет по ветвям** (branch coverage)

## 🚦 Коды ошибок

| Код | Константа | Описание |
|-----|-----------|----------|
| 0 | `_SUCCS` | Успешное выполнение операции |
| 1 | `_UNCOR` | Некорректная матрица (неправильные размеры, NULL) |
| 2 | `_ERROR` | Ошибка вычисления (несовпадающие размеры, вырожденная матрица) |

## 🎯 Ограничения

1. Поддерживаются только матрицы с элементами типа `double`
2. Максимальная точность сравнения: 1e-7
3. Нет поддержки разреженных матриц
4. Все операции выполняются в памяти (нет работы с диском)

## 📚 Математические основы

Проект реализует классические алгоритмы линейной алгебры:
- **Определитель:** вычисление через разложение по строке/столбцу
- **Алгебраические дополнения:** через миноры с учетом знаков
- **Обратная матрица:** через присоединенную матрицу и определитель

## 📈 Производительность

- **Операции O(n³):** умножение матриц, обращение
- **Операции O(n²):** сложение, вычитание, транспонирование  
- **Определитель:** O(n!) в худшем случае, оптимизировано для малых матриц
