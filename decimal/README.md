# s21_decimal+

Реализация библиотеки для работы с decimal-типом данных на языке C. Пользовательская реализация типа decimal для точных вычислений с фиксированной точкой, включая все основные арифметические операции и функции преобразования.

## 📊 Основные возможности

### Арифметические операции
- **Сложение** двух decimal чисел
- **Вычитание** decimal чисел  
- **Умножение** decimal чисел
- **Деление** decimal чисел с обработкой ошибок

### Сравнение чисел
- **Меньше** - проверка на строгое неравенство
- **Меньше или равно** - проверка на нестрогое неравенство
- **Больше** - проверка на строгое неравенство
- **Больше или равно** - проверка на нестрогое неравенство
- **Равно** - проверка точного равенства
- **Не равно** - проверка неравенства

### Преобразования типов
- **Из int в decimal** - преобразование целых чисел
- **Из float в decimal** - преобразование чисел с плавающей точкой
- **Из decimal в int** - преобразование с усечением
- **Из decimal в float** - преобразование с плавающей точкой

### Математические функции
- **Округление** до ближайшего целого (банковское округление)
- **Усечение** дробной части (отбрасывание)
- **Целая часть** (округление к нулю)
- **Изменение знака** (негация)

### Вспомогательные функции
- **Валидация** входных данных
- **Обработка ошибок** с кодами возврата
- **Нормализация** чисел
- **Проверка на ноль** и специальные значения

## 🔧 Реализованные функции

### 1. Арифметические операции
- **`s21_add`** - сложение двух decimal
- **`s21_sub`** - вычитание decimal
- **`s21_mul`** - умножение decimal
- **`s21_div`** - деление decimal

### 2. Операции сравнения
- **`s21_is_less`** - проверка "меньше"

- **`s21_is_greater`** - проверка "больше"
- **`s21_is_greater_or_equal`** - проверка "больше или равно"
- **`s21_is_equal`** - проверка равенства
- **`s21_is_not_equal`** - проверка неравенства

### 3. Преобразования
- **`s21_from_int_to_decimal`** - преобразование int → decimal
- **`s21_from_float_to_decimal`** - преобразование float → decimal
- **`s21_from_decimal_to_int`** - преобразование decimal → int
- **`s21_from_decimal_to_float`** - преобразование decimal → float

### 4. Математические функции
- **`s21_floor`** - округление в меньшую сторону
- **`s21_round`** - округление до ближайшего целого
- **`s21_truncate`** - усечение дробной части
- **`s21_negate`** - изменение знака

## 📊 Примеры использования

```c
#include "s21_decimal.h"

int main() {
    s21_decimal a, b, result;
    int error = 0;
    
    // Создание decimal из int
    s21_from_int_to_decimal(123, &a);
    s21_from_int_to_decimal(456, &b);
    
    // Сложение
    error = s21_add(a, b, &result);
    if (error == 0) {
        int sum;
        s21_from_decimal_to_int(result, &sum);
        printf("Сумма: %d\n", sum);  // 579
    }
    
    // Умножение
    error = s21_mul(a, b, &result);
    
    // Деление
    error = s21_div(a, b, &result);
    if (error == 3) {
        printf("Деление на ноль!\n");
    }
    
    // Сравнение
    if (s21_is_less(a, b)) {
        printf("a меньше b\n");
    }
    
    // Округление
    s21_decimal pi;
    s21_from_float_to_decimal(3.14159, &pi);
    s21_decimal rounded;
    s21_round(pi, &rounded);  // 3
    
    return 0;
}
```

## 🔬 Особенности реализации

### 1. **Внутреннее представление**
- **decimal:** 128-битная структура (96 бит мантисса, 32 бит служебная информация)
- **big_decimal:** 224-битная структура для промежуточных вычислений
- **Масштаб:** до 28 десятичных знаков после запятой

### 2. **Алгоритмы вычислений**
- **Сложение/вычитание:** выравнивание масштабов + поразрядные операции
- **Умножение:** алгоритм сдвига и сложения
- **Деление:** итеративное деление с накоплением результата
- **Округление:** банковское округление (round half to even)

### 3. **Обработка ошибок**
- Проверка на переполнение при каждой операции
- Корректная обработка специальных значений (INF, -INF, NAN)
- Защита от невалидных указателей

### 4. **Оптимизации**
- Быстрые пути для простых случаев (малые числа)
- Оптимизированные алгоритмы для распространенных операций
- Минимизация выделения памяти

## 📊 Технические характеристики

- **Поддерживаемый диапазон:** от -7.9×10²⁸ до 7.9×10²⁸
- **Точность:** до 28 знаков после запятой
- **Максимальное значение:** 79,228,162,514,264,337,593,543,950,335
- **Минимальное значение:** 0.0000000000000000000000000001
- **Язык:** C (стандарт C11)
- **Тестирование:** Check framework
- **Анализ покрытия:** gcov/gcovr
- **Анализ памяти:** valgrind

## 🎯 Ограничения

1. Поддерживаются только базовые арифметические операции
2. Нет поддержки тригонометрических и логарифмических функций
3. Все вычисления выполняются в памяти (нет сериализации)
4. Ограниченная поддержка специальных значений (только INF/-INF/NAN)

## 📚 Математические основы

Проект реализует вычисления с фиксированной точкой:
- **Представление чисел:** мантисса × 10^(-масштаб)
- **Нормализация:** приведение к максимальному масштабу
- **Банковское округление:** минимизация систематической ошибки

## 📈 Производительность

- **Арифметические операции:** O(n) для сложения/вычитания, O(n²) для умножения
- **Преобразования:** оптимизированы для частых случаев
- **Память:** фиксированное выделение, нет динамической аллокации во время операций
